# 🛒 BoloKart

BoloKart is a modern quick-commerce grocery delivery platform focused on delivering groceries and daily essentials from local kirana stores to homes in just **15–20 minutes**.

Built with a scalable and production-grade frontend architecture using pure HTML, CSS, and JavaScript.

---

## 🌐 Live Demo

👉 [Visit BoloKart](https://bolokart.vercel.app)

---

## ✨ Features

* ⚡ Fast and responsive UI
* 📱 Mobile-first design
* 🛍 Product category filtering
* 🔍 Smart product search
* 🛒 Dynamic cart system
* 🎟 Coupon support
* 📍 Address management
* 🔐 OTP login flow
* 📦 Order tracking UI
* 🎙 Voice quick-order system
* 🌙 Dark footer branding support
* 🧩 SVG-based branding architecture
* 📲 PWA-ready setup
